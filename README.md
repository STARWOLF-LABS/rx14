# STARWOLF LABS // RX-14 v0.3

Amber-phosphor world-band field receiver for an old iPhone.

## Update existing GitHub Pages deployment

Replace `index.html`, `stations.js`, and `manifest.webmanifest` in the root of the existing `rx14` repository.

GitHub Pages will redeploy automatically after the commit.

## Bands

- NEON — direct SomaFM cyber/electronic streams
- GHOST — vintage jazz, swing, big band and old-time radio
- TEZETA — Ethiopian jazz, funk and soul
- WORLD — Radio Garden planetary tuner
- QUANTUM — ambient, space, contemplative and Japanese environmental music

Some stations play directly inside RX-14. Others deliberately open the broadcaster's own player because of stream, licensing, or mobile-player restrictions.
